# StandardTestNGProject

## Project Overview
This repository contains a practice QA automation project (Coursework) developed using Selenium + TestNG.

## Purpose
- Practice TestNG concepts and annotations
- Learn test organization and execution
- Practice POM (Page Object Model) structure 
- Practice test suites and run method using XML
- Improve Git and GitHub workflow skills

## Technologies Used
- Selenium
- TestNG
- Java 
- Maven
- Git & GitHub

## Note
This is a practice/learning project and is intended for educational purposes.
